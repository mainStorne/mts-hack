Обучение

Как обучали

Как обучали

Ансамбль состоит из двух предобученных моделей, реранкера и жадной настройки порогов.

GLiNER

LoRA-адаптер runs/struct-lora-v21

  • Адаптер даёт сырые спаны с уверенностью. Пороги подбираются на dev, не на val.
  • Сначала перебор сетки
  • Затем покоординатный подбор tau по каждому атрибуту (0.3…0.9).
  • Итоговые значения tau_attr:
    service_state0.9tariff0.5ticket_status0.5action0.7agreement0.8
    snap_th 0.5date_tau nulldev F1 0.5602dev_gate_ok false
  • Обучался только на предоставленных тренировочных данных.

Gemma

LoRA-адаптер gemma-v21-targeted-gen

  • Дообучения этих моделей по фолдам нет. Ансамбль работает с уже готовыми предсказаниями.
  • Обучался только на предоставленных тренировочных данных.

Микробатчинг очередь

Ставим транскрипции в очередь и обрабатываем их пакетами

Сейчас модель не может обрабатывать несколько запросов параллельно. Можно ввести прикладную очередь: /extract не блокирует лок, а кладёт запрос в queue. Отдельный воркер-батчер копит элементы 5–20 мс (или до K звонков / M контекстов), объединяет контексты разных звонков в один batch_extract, затем раздаёт факты по futures'ам. Так получится эффективнее распределять ресурсы.

Каскадный роутер

По признакам определяем сложность звонка. Более лёгкий случай — отдаём маленькой модели (GLiNER). Потяжелее — большой (Gemma).

При появлении нового атрибута

Нужны примеры нового типа. Либо размеченные (gold), либо сгенерированные LLM с последующей проверкой. Без примеров в train модель тип не выучит.

Многоязычность

Чтобы добавить новый язык не нужно пересобирать пайплайн заново: достаточно собрать новый каталог атрибутов и поставить соответствующий LoRA Adapter на модель, после чего обучить.

Мы предполагаем, что модель не потеряет точность на новом языке.
