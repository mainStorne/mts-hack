# action: BERT-детектор реплик + ruT5 (итоги экспериментов)

Метрика — официальный `case_metrics.py` v2.1 на val (383 звонка, 368 gold-фактов action). Разметка организаторов
синтетическая (GLM): на action 45% gold-значений — свободный текст, у 46% нет `quote`. Сравнение значений нечёткое,
каталог на счёт action не влияет (проверено: с каталогом и без — цифры совпадают).

## Итоговая схема

1. `build_action_data.py detector` — метки реплик (есть ли action) и OOF tf-idf для отбора негативов.
2. `turn_bert.py` — mdeberta-v3-base, бинарный классификатор реплики (+ предыдущая/следующая), 1 эпоха, ~15 мин на V100.
3. `build_action_data.py gen` → `gen_seq.py --arch t5` — ruT5-base (полный fine-tune, fp32, 5 эпох, ~17 мин) пишет значение
   только для реплик с p ≥ порога детектора; на ложных репликах учится отвечать «нет».
4. `compose_final.py` — action из п. 3, остальные атрибуты из базового предсказания.

0.5 — 0.454 / 0.884. Ниже 0.2 ruT5 чаще выдумывает значение на ложных репликах.

## Что не дало прироста (val, в пределах ±0.01 или хуже)

| Идея | Результат |
|---|---|
| синтетика Haiku (+1200 реплик) для детектора | AP 0.571 → 0.556 |
| `data/gen/new_calls.jsonl` (+22 тыс. реплик) | AP 0.571 → 0.565 |
| вторая эпоха BERT | AP 0.628 → 0.633, в связке с ансамблем хуже |
| вес ошибок OOF (hard-example) | AP падает до 0.534 |
| другие модели sklearn на tf-idf | AP 0.527–0.581 |
| расширенный каталог (52 → 202 «ядра» значений) — классификатор | F1 0.489 против 0.506 |
| расширенный каталог внутри `cfe_pipeline` | F1 0.409 против 0.428 |
| zero-shot реранкер (Qwen3-Reranker-0.6B) для отсева значений ruT5 | AUC 0.548, F1 0.615 против 0.613 |
| дообучение GLiNER v21 на опорных спанах для action | action как отдельный экстрактор хуже (P 0.19 / R 0.08), детектор не лучше BERT |

Детектор действует на репликах с каталожным действием клиента (recall 0.92 при p ≥ 0.2); свободные действия ловит хуже:
клиент 18%, оператор 0% при p ≥ 0.2 (при p ≥ 0.05 — 49% и 66%).

## Другие атрибуты (проверено, не внедрено)

agreement: ни одна схема не обошла `ens-v3` (F1 0.467). Лучшие альтернативы: ruT5 на окне (реплика, соседние) 0.434,
детектор `cfe_pipeline` + ruT5 0.343–0.418, объединения с `ens-v3` 0.455–0.476 (в пределах шума). Потолок ruT5 с идеальным
детектором 0.50. Причина: у 68% gold-фактов agreement нет каталожного упоминания, а источник-реплика выбрана
произвольно (предложение оператора или согласие клиента): AP детектора 0.33 по точной реплике и 0.51 с допуском ±1.
Смена энкодера на USER2-base AP не меняет (0.343 против 0.328).
Идиомы: 2 из 60 разобранных temporal-ошибок, на polarity 0 из 13 — отдельная работа не нужна.
