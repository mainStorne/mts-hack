# mts-hack: сводка по дням

## 14 ноября: ml-трек CompactFactExtraction
- Настроена работа с GPU-сервером `inh-compute`: V100, `remote.sh`, tmux, `gpu-free` и `gpu-restore`.
- Обучали структурные LoRA-экстракторы на `Qwen3.5-0.8B` и сравнивали варианты:
  - `struct-lora`: F1 0.547 на test, 0.519 на noisy-test.
  - `struct-lora-dn` (с полем `outcome`): dev F1 0.34. Сравнение с `struct-lora` признано невалидным: разные данные и поле `outcome`.
  - `struct-ent3`, `struct-fact3`: F1 0.27–0.32, слабее.
  - `struct-lora-v21`: перебор порогов на данных v2.1, dev F1 ≈ 0.51.
- GLiNER-классификатор: пороги tau 0.3–0.9, правила дат (`oldrules` / `newdates`), варианты val и val_noisy.
- Вынос детерминированных частей из модели: нормализация относительных дат, привязка реплик к говорящему, словарь полярности. Даты и говорящий решены правилами, полярность осталась за моделью.
- Обсуждение замены токенизатора для русского (`gliner-multitask-large-v0.5`, DeBERTa → mDeBERTa). Вывод: подменить токенизатор нельзя, нужна замена или дообучение энкодера.
- Запущены два обучения Gemma 3 1B + LoRA на данных v2.1.
- Убран шаг выбора рабочей конфигурации. Образы остаются с умолчаниями vLLM (batch 16, промпт 3072, генерация 1024). В `curve.py` кривая «ресурсы × качество» показывает все точки со столбцом `pareto`.
